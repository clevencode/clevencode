# Clevenider Petit | Portfólio

Portfólio pessoal — HTML, CSS e JavaScript puro.

## UI

Visual alinhado ao branding **clevencode**: Swiss / tech minimal, Inter, azul de ação `#2563EB`, preto `#0D1117`.

## Seções

- **Hero** — apresentação, typing e foto
- **Sobre mim** — bio e estatísticas
- **Skills & Ferramentas** — tecnologias
- **Projetos & Experimentos** — cards de projetos
- **Contato** — e-mail e redes

## Como rodar

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080/`.
