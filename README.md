## Sobre

Site de portfólio pessoal com design escuro e minimalista, inspirado na estética Apple. Apresenta minhas informações, habilidades, projetos e formas de contato.

### Seções

- **Hero** — Apresentação com efeito de digitação animado e orbs flutuantes
- **Sobre mim** — Foto de perfil, bio e estatísticas
- **Skills & Ferramentas** — Cards interativos com as tecnologias que utilizo
- **Projetos & Experimentos** — Cards com efeito glow, descrição e tags de tecnologia
- **Contato** — E-mail e links para redes sociais

### Funcionalidades

- Tema escuro elegante com acentos roxos
- Navbar fixa com glassmorphism e scroll tracking
- Efeito typing animado ciclando entre frases
- Animações reveal on scroll (Intersection Observer)
- Hover effects nos cards de skills e projetos
- Smooth scroll para navegação interna
- Layout totalmente responsivo (mobile-first)
- Menu hamburger para dispositivos móveis

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/clevencode/clevencode.git
   cd clevencode
   ```

2. Inicie um servidor local:
   ```bash
   python3 -m http.server 8080
   ```

3. Acesse no navegador:
   ```
   http://localhost:8080
   ```

> Qualquer servidor HTTP estático funciona (Live Server do VS Code, `npx serve`, etc.)
